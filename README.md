# Pizza Perfection Polls

A blank Next.js playground for exploring a small voting product around pizza opinions. Right now it is still the default Next.js starter screen; the README is intentionally more honest than the generated template.

## What this is exploring

- How a lightweight poll feels when the subject is subjective and local
- Next.js App Router and the basic React page structure
- A possible path from one-question voting to aggregate results

## Current state

There is no poll logic yet and no database. Start the development server with:

```bash
npm install
npm run dev
# open http://localhost:3000
```

The first meaningful slice would be one poll, one vote per browser, and a result view. Everything beyond that should earn its way in through use.
